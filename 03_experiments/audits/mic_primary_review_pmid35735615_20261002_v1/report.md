# Ludwig 等 2022：原始 apidaecin 测定审计

[原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9221748/)，PMID 35735615，DOI 10.3390/cimb44060174，CC BY 4.0。结构化 Table 1 与 Methods 2.2/2.3 明确五条人工合成游离酸端肽、Rosetta DE3 pLysS 菌株、培养基和 MIC 端点；未使用噬菌体表达或联合治疗读数作为肽 MIC。

Api801、Api805 的所有已报告 MIC 均支持阳性；Api810 在两种培养基均支持阴性。Api802 有 64 µg/mL 空档测定，保守排除整条分子；Api806 两种培养基分别给出阳性和阴性，排除整条分子。未测定不补值。最终为 3 条候选分子、4 条候选测定。

与现有 38 条逐成员核对共 114 对，达到 0.40 的边为 3；同源关系和共享论文均必须连接，不能把 Api810 当作新独立组件。完整证据复核、队列冻结及五折门禁尚未通过，训练释放数为 0。
