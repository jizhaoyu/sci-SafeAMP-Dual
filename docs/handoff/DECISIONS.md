# SafeAMP-Dual 科学与架构决策记录 (DECISIONS)

本文档记录经论证固定的研究端点、算法定义与边界选择。未获特别批准，不得静默违背。

---

### D01：冻结研究端点与二分类标准
- **抗菌端点 (AMP)**：大肠杆菌 (*Escherichia coli*) MIC ≤ 32 μg/mL 判定为阳性 (1)，≥ 128 μg/mL 判定为阴性 (0)。
- **溶血端点 (Hemo)**：人红细胞 (Human erythrocytes) HC50 ≤ 100 μg/mL 判定为阳性 (1)，≥ 250 μg/mL 判定为阴性 (0)。
- **中间值与未测值处理**：32 < MIC < 128 或 100 < HC50 < 250，以及缺失测量的记录，统一标记为未知 (NaN)，**绝不强行二分类，绝不自动充填阴性**。
- **分子范围**：限制为 10–50 个标准氨基酸、单体 (Monomer)、无修饰线性肽。修饰肽与非标准氨基酸不直接作为无修饰肽使用。

### D02：序列隔离算法定义 (Sequence Identity Definition)
- **算法模型**：全局 Needleman-Wunsch (NW) 动态规划比对。
- **打分规则**：Match = +2，Mismatch = -1，Gap open/extend = -2。
- **规范方向与同分策略**：序列对输入按字典序标准化以确保对称性，回溯同分时优先沿对角线 (Match/Mismatch)。
- **相似度公式**：$\text{identity} = \frac{\text{matches}}{\min(\text{length}_a, \text{length}_b)}$。
- **连通分量规则**：当 $\text{identity} \ge 0.40$ 时在两序列节点间建立无向边；连通分量 (Connected Components) 必须完全落在单一划分中，绝不能跨越训练集与验证集/测试集。

### D03：真实数据与来源独立性
- **DBAASP**：指定为开发候选集主要来源。
- **DRAMP**：指定为独立外部验证候选集来源，不得混入开发集。
- **交叉排除原则**：与开发集存在相同原始文献、相同分子或同源序列（$\ge 0.40$）的外部候选序列，必须被排除出外部验证队列。
- **真实性约束**：仅采纳具有实际湿实验测量佐证的数据，严禁使用模型预测分、随机序列或计算虚构数据作为标签。
