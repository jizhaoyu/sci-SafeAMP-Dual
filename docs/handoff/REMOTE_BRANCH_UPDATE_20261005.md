## 留在本地的依赖

原论文、原文区域复制、附图、补充材料、原始下载、来源快照、含原文的 MIC 交付 ZIP、模型/特征二进制、凭据文件、临时办公运行环境不进入本次提交。已有 Git 历史保持原样，不执行历史重写。

远程仓库保存代码和审计结论，不是完整训练交付包。部分审计记录中的 input/path/sha256 仍引用本地保留的原文件，这是审计绑定，不是它们已经公开发布的声明。单独克隆仓库不能据此声称所有数据和模型已具备，也不能绕过缺文件门禁。

需要实际模型重放或完整源证据复核时，使用已有本地、获相应使用授权的交付资料并保留原相对目录；先核查许可和所有绑定摘要。DeepSeek 测试入口还会核查原科学状态与 MIC ZIP/manifest，缺失时拒绝开始，而不会替换成模拟结果。网页 `/api/ai_report` 仍为本地报告，没有借此次推送接入第三方。

## 字节与密钥

`.gitattributes` 对审计相关代码和产物禁用 Git 自动 LF/CRLF 转换，以保留实际 SHA256 的字节定义；未运行历史文件 renormalize。

本次候选发布文件扫描现有配置密钥和私钥内容，输出只记录文件名及问题类别。旧 DeepSeek 明文密钥已从当前调用脚本移除，但历史提交不被重写，密钥仍须账户所有者在控制台轮换。环境文件和私钥不发布。
