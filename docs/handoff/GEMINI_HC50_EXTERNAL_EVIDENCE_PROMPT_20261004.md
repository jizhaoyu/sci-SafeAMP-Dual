## 5. 不可更改的分子与端点边界

### 分子身份

- 长度 10–50，20 种标准天然氨基酸、既有协议支持的 L 型、线性、未修饰单体。
- 核查 N/C 端、酰胺化、环化、二硫键、其他共价修饰及非天然残基。
- 原文中受测对象必须明确对应所记录的序列和分子形式；不能只靠同名肽或数据库的“free”类别推断。
- 分子质量必须注明中性平均质量、单同位素质量或质谱离子/加合物形式。不能把 `[M+H]+`、近似分子量或质谱单项证据直接当作完整身份确认。
- 树脂或合成方法必须对应具体受测分子。不能因论文提到某种树脂，就替另一种分子推断末端形式。
- 同一序列的酸型、酰胺型、D 型、环状型等不能合并；更不能用一种形式的 MIC 配另一种形式的 HC50。
- Cys 数量是线索，不是替代原文拓扑证据的门禁。环肽、二硫键肽和非天然形式只能另表保存，不进入当前严格基线。

### MIC

- 目标严格为 E. coli，记录具体菌株或分离株。
- 记录真实的 MIC 和方法；MBC、抑菌圈、时间杀灭、组合/FIC、预测活性不能替代 MIC。
- 数值、范围、`>`、`>=`、`<`、`<=` 均保留原文表达和开闭区间，不把删失值改成确切值。
- 既有规则：MIC 上界 <=32 µg/mL 为 amp=1；下界 >=128 µg/mL 为 amp=0；不能确定标签的值保持 unknown。

### HC50

- 对象必须明确为人红细胞。绵羊、牛、兔、小鼠等动物红细胞或种属未明确的 RBC 不可替代。
- 肝细胞、肿瘤细胞、其他细胞的 IC50/CC50/EC50，不是目标 HC50。
- 优先使用原文或作者原始表格明确报告的 HC50 及其真实测定/拟合依据。
- “无溶血”“低毒性”“某浓度下 0.7% 溶血”“LD50”不能自动转换为 HC50。
- 不依据单个浓度点、默认单调性、最高测试浓度或模型曲线，编造 `HC50 > X`。
- 原文明确报告的 HC50 删失值可以保留并按既有区间规则审查；保留其支持的测试范围和原文位置。
- 图中读取或数字化估计值必须标注 figure_estimate、读取方法和误差。没有原文明确端点及可审计的既有准入规则时保持待核实，不自动转为正式数值或标签；禁止把约值写成精确值。
- hemo=1 表示高溶血端点：HC50 上界 <=100 µg/mL。
- hemo=0 表示该端点下的低溶血类别：HC50 下界 >=250 µg/mL；不等于临床安全。
- 阈值之间、证据不足或标签冲突时保持 unknown；不人工输入类别。

### 单位与条件

- 保留原值和原单位。既有标准化单位为 µg/mL；mg/L 等价；µM 换算需要实际受测分子的可复核中性分子量及换算公式。
- 拒绝单位不明或未经解决的分子量/端基冲突；不能仅按肽名查一个默认分子量。
- 记录培养基、菌株、盐、pH、温度、时间、接种信息，及人红细胞来源/供体、红细胞比例、洗涤/缓冲条件、暴露时间、温度、对照与读出方式。不要给出新实验操作方案。
- 未报告的次要条件写 `not_reported`；不能填入“常见标准条件”。关键对象、分子形式、数值或单位无法确定则待核实。
- 正文、补充表、数据库、图表有不同值时全部列入冲突表。不能挑选支持目标标签的条件。相反标签不能被平均、投票或删去不利观察而消解。

## 7. 正式外部独立性与全员序列审计

必须阅读并复用既有冻结比对定义：

- 全局 Needleman–Wunsch，match +2、mismatch -1、gap -2。
- 输入按字典序定向；并列 traceback 依次 diagonal、up、left。
- identity = 相同残基列数 / 全部比对列数；gap 列计入分母并视为不匹配。
- identity >=0.40 构成同源边；不得仅用聚类代表、局部比对、BLAST identity 或长度比过滤代替。

每条外部候选与全部 417 个开发成员比较，保存完整比较表和最近成员。任一对 >=0.40 即不能进入严格外部队列。确切等于 0.40 也必须失败。若缓存相同计算，仍保留完整候选/开发成员映射。

规范化实际测量研究的 DOI、PMID、PMCID 并维护别名表。不能把被引用的方法论文当成该测量研究，也不能把不同数据库记录当成独立来源。测量研究与开发来源重合则外部独立性失败。

另外记录与当前 17 分子 MIC 队列及所有已用于训练、模型选择或已查看结果的历史来源是否重合。分别输出“原正式开发集隔离”和“历史暴露/探索队列重叠”。不得因没出现在 417 条里，就宣称它从未被项目使用或是盲外部测试数据；不能静默改变正式开发集定义。

外部池内部也执行全员比较，保存关系和研究分组，报告独立分子/研究/组件数量。多个同源分子、同一论文的多次表格提及或技术重复，不得计成多个独立研究。

证据审查决定与序列审计结果分别保存。不能把同源超标说成原始测定不存在，也不能把序列隔离通过说成证据已核实。

所有“原文已核实”都要能指出本地真实文件与精确位置，审查方式标注 `agent_primary_source_review`，不得声称独立人工评审。没有实际访问本地文件、运行脚本或获取全文时，明确写未执行；网页聊天只能交付可下载的证据表/材料或其真实引用，不能声称已经写入 D 盘。

## 10. 需要实际验证的审计行为

测试仅针对新审计脚本，在新目录内使用合成测试输入验证软件行为。合成输入不得混入真实证据表。至少验证：

- 动物 RBC、对象未明、单浓度溶血百分比、MBC、数据库类别不能产生目标资格。
- 酸型/酰胺型混配、未确定身份、单位或删失值不能被静默改写。
- 阈值区间推导与未知值处理正确；相反标签不能通过删行或平均解决。
- DOI/PMID/PMCID 别名合并、测量研究重叠与方法引用区分正确。
- gap、短序列桥接、对称定向、identity 恰为0.40及成员/代表差异按冻结定义处理。
- 原始来源或输入摘要变化、完整比较表缺行时审计失败。
- 输出已存在时拒绝覆盖。

报告实际命令、退出码和结果。不能把计划运行写成已运行，不运行现有训练入口去“验证准备好了”。

## 11. 阶段顺序与停止条件

1. 读取协议与基线，核对摘要，列出禁止修改清单；有冲突先记录。
2. 记录检索计划，先核查旧线索，再扩展真实原始研究。
3. 分子身份、原始端点、单位和对象逐项审查；保存所有冲突观察。
4. 按冻结规则推导标签；建立 A 池和 B 候选池。
5. 执行研究独立性、全员相似度和历史暴露审计，生成分开的门禁结果。
6. 核对表间完整覆盖、文件摘要和新脚本回归，交付报告。

输入基线摘要冲突时不得继续声称正式审计。资料访问失败不需要停止所有其他研究，但相关候选不能放行。资源、时间或工具耗尽时交付已有证据、准确覆盖范围与未完成清单，不伪造“全网检索完毕”。
