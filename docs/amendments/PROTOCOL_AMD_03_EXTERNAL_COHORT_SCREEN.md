# Protocol Amendment 03：正式双任务外部候选队列系统性筛查与穿透式审计协议

**协议 ID**：`protocol-amd-03`  
**拟定日期**：2026-10-03  
**适用范围**：SafeAMP-Dual 正式双任务（Phase D: *E. coli* MIC + 人红细胞 $\text{HC}_{50}$）外部独立测试队列的检索、穿透审查与准入审计。  
**前置约束**：受 `04_paper/research_status.json` 中不可变门禁与 `protocol-amd-02` 全员同源隔离规范严格约束。在满足全部准入条件前，正式科研状态严格维持 `blocked`。

---

## 一、协议背景与核心瓶颈

在 SafeAMP-Dual 研发体系中，正式科研评估必须同时满足大肠杆菌（*Escherichia coli*）抗菌最小抑菌浓度（MIC）与人红细胞半数溶血浓度（$\text{HC}_{50}$）的双任务联合预测。

前期审计确认：
1. **开发集现状**：`02_code/data/sources/combined_v3_evidence_clean_20261001/records.csv` 包含 417 条 DBAASP 实验记录（对应 318 条唯一无修饰天然单体肽序列），经 `protocol-amd-02` 划分为 89 个连通簇（最大连通簇含 318 条记录）；
2. **外部队列阻断**：历史外部数据（13 条）因缺乏独立原始测定依据与零泄漏保证被全数剔除；2026-10-01 筛查的 Conlon 2004（PMID 15207717）因文献重叠与同源超标（最大一致性达 0.958）被否决；Wang 2025、Pandi 2023、Tripathi 2015 等主流高通量文献因全员 C 端酰胺化或同源 $\ge 0.40$ 被科学否决；
3. **当前状态**：外部队列合格有效记录数为 0，系统状态处于客观科学阻断（`blocked`）。

为破局正式双任务外部队列，本协议制定严格的系统性筛查标准与穿透式文献审计程序，防止任何形式的数据污染与伪阳性结论。

---

## 二、四大科研诚信硬性准入门禁 (Gating Criteria)

任何进入正式外部评估集（External Test Set）的候选多肽，必须同时 100% 满足以下四重门禁：

### 门禁 1：化学形式全同性与序列规范
1. **长度与残基限定**：长度严格在 10–50 个氨基酸之间，仅由 20 种标准天然 L-氨基酸构成，不含非天然残基（如 D-型、Orn、Dab 等）。
2. **双测定化学形式完全全同**：同一条多肽序列在 *E. coli* MIC 测定与人红细胞 $\text{HC}_{50}$ 测定中，必须采用**完全一致的化学合成或天然提取形式**。
3. **未修饰游离酸要求**：默认基准要求为未修饰天然游离羧酸（`-COOH`，`modifications=none`）。
   - **绝对红线**：严禁将游离酸状态测得的 MIC 与 C 端酰胺化（`-NH2`）测得的 $\text{HC}_{50}$ 进行人工拼接！
   - 凡文献中明确使用 Rink Amide、MBHA、RAM 等树脂合成，或质谱/核磁确认为 C 端酰胺化的多肽，一律打标为酰胺化排除项。
4. **二硫键与拓扑约束**：
   - 优先选择天然线性多肽（Cys 计数 $\le 1$）；
   - 若引入含二硫键的天然环肽（如 Defensins、Cyclotides），其 MIC 与溶血测定必须处于相同氧化还原态（天然二硫键配对完整），且其无二硫键特征表征的拓扑局限性必须在方法学中专门声明。

### 门禁 2：双任务定量实测数值与阈值可判定性
1. **严禁二次数据库整理值**：不接受任何未附带文献证据链的数据库二值分类标签或单纯文本“active / inactive”。必须能回溯到原始论文图表中的具体实测浓度数值。
2. **两任务兼备**：每个候选分子必须同时测定并报告 *E. coli* 抗菌活性与人红细胞溶血活性。
3. **MIC 判定阈值**（基于微量肉汤稀释法 broth microdilution）：
   - 阳性（活性，`amp = 1`）：$\text{MIC} \le 32\ \mu\text{g/mL}$；
   - 阴性（无活性，`amp = 0`）：$\text{MIC} \ge 128\ \mu\text{g/mL}$；
   - 灰色不确定带：$32 < \text{MIC} < 128\ \mu\text{g/mL}$，不作为决定性标签。
4. **$\text{HC}_{50}$ 判定阈值**（靶标严格限定为人红细胞 Human RBC）：
   - 阳性（高溶血/毒性，`hemo = 1`）：$\text{HC}_{50} \le 100\ \mu\text{g/mL}$；
   - 阴性（低溶血/安全，`hemo = 0`）：$\text{HC}_{50} \ge 250\ \mu\text{g/mL}$；
   - 灰色不确定带：$100 < \text{HC}_{50} < 250\ \mu\text{g/mL}$，不作为决定性标签；
   - 严格排除绵羊、牛、小鼠等非人红细胞溶血实验。

### 门禁 3：全员全对齐零泄漏同源隔离
1. **比对算法不可变性**：严格继承 `protocol-amd-02` 冻结算法：全局 Needleman-Wunsch 动态规划（Match `+2`，Mismatch `-1`，Gap `-2`，字典序定向优先对角）。
2. **一致性定义**：
   - 分母统一采用最优比对的总列数（`identity_mode='alignment'`），含 Gap 列计入分母，不计入相同残基数。
3. **全员跨队列门禁**：
   - 候选多肽与 417 条开发集记录执行全员两两比对；
   - **最大比对一致性必须严格满足 $\text{max\_identity} < 0.40$**；
   - 只要任何一对比对一致性 $\ge 0.40$，该候选分子立即被同源隔离门禁否决。

### 门禁 4：研究源头与文献独立性
1. 候选多肽的原始测定文献（PMID/DOI）不得与开发集中 417 条记录的引文源重叠。
2. 必须进行穿透式原文核查（Primary Literature Review）：逐篇核验论文 Materials and Methods 中的菌株来源（优先 ATCC 25922 或临床分离株）、培养基（MHB / CAMHB）、红细胞供体及稀释方法。

## 三、候选分子分级与审计流水线 (Screening Tiers)

根据穿透审查结果，候选多肽分为三类归档：

1. **Tier 1（最高优先级·天然线性自由酸候选）**：
   - 满足全员 NW $< 0.40$；
   - 天然来源或固相合成明确为自由羧酸端（`-COOH`，无酰胺化）；
   - Cys 计数 $\le 1$（天然线性）；
   - 具有明确的 *E. coli* MIC 与人红细胞溶血实测浓度。
2. **Tier 2（方法学探索级·含二硫键/天然环肽候选）**：
   - 满足全员 NW $< 0.40$；
   - 具有多对二硫键或环状骨架（如植物环肽 Cyclotides、动物防御素 Defensins）；
   - 虽满足双活性测定，但因序列特征提取器缺少 3D 构象/二硫键连接表征，仅作为拓展探索候选，不得混入基准线性评估。
3. **Tier 3 / Disqualified（排除池）**：
   - 明确 C 端酰胺化；
   - 同源一致性 $\ge 0.40$；
   - 仅有单任务数据或靶细胞为动物红细胞；
   - 来源文献重叠。

## 四、阻断解除准则 (Unblocking Criteria)

1. 若在 Tier 1 中筛选出满足所有四大门禁的合格候选多肽，且满足：
   - 样本量 $N \ge 5$；
   - 在双任务上均具备正负类观测覆盖（MIC 阳性/阴性均存在，$\text{HC}_{50}$ 阳性/阴性均存在）；
   - 通过 `02_code/research_data.py` 的全量完整性校验。
   此时方可起草外部队列建立方案，向用户汇报后方可审慎推进阻断解除。
2. 若 Tier 1 中合格候选不足或标签严重单侧缺失，**必须严格如实维持 `research_status.json` 的 `blocked` 状态**，并在学术成果中完整披露真实筛选漏斗与实验数据现状。严禁人为调参或放宽门禁。
