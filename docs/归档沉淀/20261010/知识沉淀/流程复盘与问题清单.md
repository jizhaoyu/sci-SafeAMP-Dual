# 流程复盘与问题清单

## 已反复出现的问题及处置原则

| 问题 | 已形成的原则 |
|---|---|
| 特征名称比实际算法更强 | 检查调用和权重，名称与实现分开；兼容文件名不证明预训练执行 |
| 只看目录项或摘要便声称可用/复现 | 实际注册、模型文件、输入版本、逐条预测及故障边界分别验证 |
| 只按一个实体分组却解释为双冷 | 双冷验证训练块同时排除两侧验证实体；验证实际索引 |
| 对角五块只有20% OOF | 验证覆盖完整性，不能补零或用训练预测冒充其余OOF |
| 元层OOF拟合分数被当无偏评价 | 基模型OOF和元层拟合诊断分别标记，外层评价职责明确 |
| 多配对被当独立样本 | 以研究问题规定实体重采样及条件集合，种子不是数据集复制 |
| p值删了主比较却留相关性p值 | 查实际JSON/函数字段，而不只看报告声明 |
| CSV列齐全仍无法识别实验 | 用experiment_id、设计、种子、特征版本、配对和真实折次构成可追溯身份 |
| 整改时新增了不存在模型/路径/摘要 | 从实际文件生成索引；缺失保持未知，不为完整性编造 |
| 训练时长/硬件从别处移植 | 引用真实日志及执行实现；恢复/后处理时长不当训练总时长 |
| 提示词表格转录错误 | 原JSON和检查点优先，写差异说明，不调整结果迎合文本 |
| 哈希被解释成科学有效 | 哈希仅验证身份；来源语义、划分及推断另行检查 |
