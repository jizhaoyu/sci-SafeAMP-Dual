## 二、四大独立待审决策清单 (Pending Decisions)

### 1. [DEC-01] 内层交叉验证方案最终选择
* **决策背景**：
  * 方案 1（核心推荐）：采纳 **25 块棋盘 2D Bicluster GroupKFold 设计**。将 55 药与 304 靶各分为 5 组，生成 25 折互斥双冷验证块，排除半冷配对，内层 OOF 预测 100% 覆盖全部 16,720 对；元学习器样本量与配对对照完全对齐。
  * 方案 2（备选方案）：退回 **单实体冷药 5 折 GroupKFold**。仅对药物分组，靶点完全重叠，拟合 5 次；但内折仅模拟冷药，无法对齐外层双冷拓扑。
* **推荐意见**：**(Recommended)** 采纳方案 1（25 块棋盘设计）。该设计在科学上消除了双冷验证与配对对照在元学习器样本量上的 5 倍混杂，且完全阻断了实体泄漏。
* **状态**：待用户与复审方裁定。

---

### 2. [DEC-02] 跨数据集确认基准 (KIBA) 协议定义
* **决策背景**：
  * KIBA 数据集清洗基准为 2,111 药、229 靶、118,254 配对；
  * KIBA 标签为综合积分打分（KIBA score，典型范围约 0~17.2），非连续负对数摩尔亲和力 $pKd$。
* **选项分支**：
  * 分支 A（跨数据集方法学可重复性检验）：在 KIBA 数据集上按照相同的 2D 棋盘双冷验证架构独立训练模型并评估其排序 CI，检验方法学结论（Stacking vs Ridge）是否具有跨数据集稳健性；
  * 分支 B（直接零样本跨域外推）：使用 DAVIS 训练的 2988D 模型直接对 KIBA 配对推断。由于两数据集靶点激酶家族定义差异及亲和力单位不兼容，必须做 Min-Max 尺度对齐或纯排序检验。
* **推荐意见**：**(Recommended)** 采纳分支 A。将 KIBA 定位为独立的方法学可重复性检验，而非直接零样本外部验证。
* **状态**：待用户与复审方裁定。

---

### 3. [DEC-03] 特征消融梯队范围
* **决策背景**：
  * 当前已建立严格单变量解耦的四级特征消融梯队：
    * F1: 基础基线 (分子 2056D + 激酶 100D = 2156D)；
    * F2: 隔离 ESM-2 边际贡献 (分子 2056D + [激酶 100D + ESM-2 320D] = 2476D)；
    * F3: 隔离 512D 几何边际贡献 ([分子 2056D + 512D 几何] + 激酶 100D = 2668D)；
    * F4: 全量复合模型 (分子 2568D + 激酶 420D = 2988D)。
* **选项分支**：
  * 分支 A（推荐执行）：在正式实验中执行上述四级单变量消融，严格度量 ESM-2 与 512D 几何模块的经验预测贡献；
  * 分支 B（精简执行）：仅对比 F1（无生物大模型）与 F4（全量复合），节省约 40% 计算预算，但牺牲单模块因果归因精度。
* **推荐意见**：**(Recommended)** 采纳分支 A。单变量因果解耦是回答同行评审对预训练生物表征边际价值质疑的核心支撑。
* **状态**：待用户与复审方裁定。

### 4. [DEC-04] 标准 RDKit Morgan 指纹替换决策
* **决策背景**：
  * 当前代码中的 2048 位分子指纹为项目自定义实现的循环 Weisfeiler-Lehman 拓扑哈希指纹，非化学信息学行业通用的 RDKit 官方实现（`AllChem.GetMorganFingerprintAsBitVect(mol, radius=2, nBits=2048)`）；
* **选项分支**：
  * 分支 A（替换为行业标准）：在正式训练获批后，引入 RDKit 标准 Morgan 指纹替换当前自定义指纹。优势：提高科研论文的行业公认度与第三方复现性；代价：历史保存的 2056D/2988D 离线特征张量需全量重新提取，耗时约 25~30 秒。
  * 分支 B（维持现状并如实命名）：在协议与论文中如实定名为“自定义 Weisfeiler-Lehman 拓扑哈希指纹 (2048D)”，维持现有已提取离线张量。优势：零额外代码变更风险，完全复用历史保存特征；代价：在化学信息学同行评审中可能受到关于指纹标准化程度的质询。
* **推荐意见**：**(Recommended)** 建议在获得正式整改授权后采纳分支 A（替换为标准 RDKit Morgan），确保研究遵循化学信息学通用规范。
* **状态**：待用户与复审方裁定。
