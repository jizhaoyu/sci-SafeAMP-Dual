# Gemini 后续论文写作交接说明

请以本目录的 `论文工作稿_中文.md` 为起点，先读 `主张与证据表.md`、`evidence/claims.csv`、`evidence/source_manifest.json`、`参考文献核验.md`、`待补证据与作者确认.md`，再写作。数值表和图均来自已验收产物，不需要再训练或重跑实验。

## 写作方向

研究题目限定为DAVIS本地版本上内层验证设计与特征模块的探索性比较。一个主要问题：同一双冷域中，Stacking-D相对Stacking-A的五种子平均CI差。两个辅助问题：模块对照与长序列处理。不新增未执行模型，不把现有结果包装为新架构或确认性优势。

稿件必须同时保留：主区间含0、Ridge优于当前F4集成、ESM/启发式模块在seed42下的不利结果，以及单模型出现不同模块效应。当前没有完整外部确认或湿实验，历史测试已查看，训练前日志存在缺失。

## 允许的下一轮工作

- 在新的独立文档目录修改论文文字、图注、结构、参考文献位置与已有结果表展示；保留本目录作为起点，不覆盖历史资料。
- 核对原始来源和已有文件，记录真实支持及定位；作者核验尚未完成时，不能将 `human_verified` 自动改为true。
- 必要的公开文献核验仅用原论文/官方来源，不能上传未发表工作区材料，不能用搜索摘要代替原文。
- 将确实尚未解决的问题保留在作者确认清单；未确定期刊时，不宣称满足某刊要求。

## 禁止事项

不得训练、微调、调参、换种子、改划分、提新特征、下载模型、安装依赖或修改业务默认模型。不得编造作者、基金、声明、数据清洗原因、硬件、耗时、算法、数值、DOI或已完成实验。不得删除不利模型结果或用别的特征版本最佳值替代当前结果。不得执行投稿、公开上传、Git提交/推送或向他人发送材料。

## 交付规范

提交修订稿、逐项修改说明、主张—证据表和参考核验记录，明确未完成的作者确认项。凡变动科学事实，先更新证据及表，再修改正文；所有图表标题和样本单位需一致。数据或实验方案变更只列为待审提议，不执行。

最重要的表达边界：**“正向点差，但描述性区间包含0，当前证据不足以确认稳定优势。”** 不替换成“显著提高”“证明无差异”“统计等效”或“首次解决零泄漏”。
