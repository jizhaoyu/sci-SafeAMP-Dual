## 本包核心事实

平均主CI差约+0.070184，但95%实体描述性区间含0。当前结果不能确认稳定泛化优势。Ridge较当前F4复杂模型更好，辅助消融与长序列结果为seed42探索性对照；这些不利结果不能删除。

五种子属于计算重复，不能当五个独立测试数据集。两个主要统计区间是同一历史探索性数据上的条件经验描述，没有p值或确认性显著性结论。

## 可编辑图表

`figures/` 有4张PNG及对应SVG。PNG为300 DPI通用稿，SVG保留可编辑文本；不承诺特定期刊合规。图表值来自本包CSV，原始高精度预测仍在历史检查点中。图1经过标签布局修订，所有数据点未移动。

`tables/` 有8张主题CSV和76实验的完整汇总表。CSV列名为机器可读英文，正文与图注为中文。

## 证据与复现

`evidence/source_manifest.json` 包含本地源文件、公开参考来源、98个原始划分/检查点/模型文件的事后摘要绑定。`evidence/claims.csv` 保存主张文本摘要、定位和来源ID；可读正文在主张表中。所有来源当前均标作者待核验，不伪造人工签认。

`reproduction/` 保存生成和验证方法。`artifact_manifest.json` 为本包文件摘要，不能单独证明历史科学有效或不存在泄漏。文档状态不表示稿件可投稿；用户需要确认作者、刊物、声明、来源与论证定位。

本包采用 scientific-writing 与 scientific-visualization 技能组织证据与图。程序性方法来源为Kassis等(2026)的[Scientific Agent Skills](https://arxiv.org/abs/2609.00065)，已记录在参考核验文档；它不是本项目性能结论的证据。原DAVIS出版全文和ESM-2出版页存在访问限制，未将未读内容标为已核实。
