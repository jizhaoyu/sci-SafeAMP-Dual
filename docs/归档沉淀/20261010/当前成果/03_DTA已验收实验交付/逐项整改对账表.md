## 三、真实事实与数据一致性对账汇总

1. **原数据集规模**：`03_experiments/prepared/dti_davis_clean_features_20261009_v1/pairs_metadata.csv` 全集共 68 个药物、379 个靶点、25,772 对结合数据；训练块包含 55 个药物、304 个靶点、16,720 对结合数据。
2. **测试评估域样本数**：
   * `strict_dual_cold_test`：975 对样本（13 个未见测试药物 $\times$ 75 个未见测试靶点）；
   * `cold_drug_test`：3,952 对样本；
   * `cold_target_test`：4,125 对样本；
   * `cold_target_test_15_long_targets`：825 对样本（针对 15 个序列长度大于 1022 的长靶点）。
3. **真实模型实测指标 (Design D, Seed 42, strict_dual_cold_test)**：
   * **Ridge**：CI = `0.715705`，RMSE = `0.803974`，MAE = `0.552477`，Pearson $r$ = `0.380640`，Spearman $\rho$ = `0.384406`。
   * **HistGradientBoosting**：CI = `0.584157`，RMSE = `0.892019`，MAE = `0.606272`，Pearson $r$ = `0.147285`，Spearman $\rho$ = `0.148171`。
   * **RandomForest**：CI = `0.557005`，RMSE = `0.909975`，MAE = `0.640619`，Pearson $r$ = `0.121321`，Spearman $\rho$ = `0.101526`。
   * **Stacked Ensemble (NNLS)**：CI = `0.681706`，RMSE = `0.839589`，MAE = `0.558089`，Pearson $r$ = `0.268793`，Spearman $\rho$ = `0.329080`。
4. **Ridge 在消融版本中的真实 CI (Design D, Seed 42)**：
   * F1 (2156维): CI = `0.724456`
   * F2 (2476维, +ESM2): CI = `0.715267`
   * F3 (2668维, +几何): CI = `0.724740`
   * F4 (2988维, 全复合): CI = `0.715705`
   *(明确说明：0.7247 来自 F3 Ridge，不跨组与 F4 替换)*。
5. **L1 vs L2 真实对比 (Design C, Seed 42, 15 长靶点 / 825 对)**：
   * L1 (截断至 1022 氨基酸): Stacking CI = `0.790030`
   * L2 (滑动窗口全局平均): Stacking CI = `0.786280`
   * 点估计差异：$\Delta = -0.003750$。（采用设计 C 冷靶分组，非设计 D）。
