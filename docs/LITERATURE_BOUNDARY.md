# 文献边界与外部数据候选

本次核对是针对整改的定向检索，不是系统综述；不能声称覆盖全部近期工作。

## 对创新性主张的约束

- HAPPENN（Scientific Reports, 2020），DOI 10.1038/s41598-020-67701-3，已有神经网络溶血预测。原错误 DOI 已修正。数据库研究与实验的物种、剂量、标签阈值仍需逐条核查，不能直接当成本项目 HC50 外部集。原文：https://www.nature.com/articles/s41598-020-67701-3 。
- HemoPI2（2024），DOI 10.1093/bib/bbae342，原文区分溶血活性与效力，使用机器学习、混合方法和大型语言模型。不能把引入蛋白质语言模型本身作为独创贡献。原文：https://pmc.ncbi.nlm.nih.gov/articles/PMC11285420/ 。
- A multi-task deep learning approach for improving peptide toxicity prediction（2022），DOI 10.1093/bioinformatics/btac221，已有多任务肽毒性预测；本研究必须基于相同端点和隔离条件重新界定贡献。原文：https://academic.oup.com/bioinformatics/article/38/10/2975/6564258 。
- AMPBench-MT（arXiv:2607.25518，2026-07-18 v1）是预印本，提出多个 AMP 相关任务、理化先验和序列家族隔离。它不是已确认的同行评议结论或本项目的已执行基线。原文：https://arxiv.org/abs/2607.25518 。

优先研究问题仍是：严格证据和隔离下，联合学习是否改善权衡与校准。结果可能为无改善，应如实报告。

## 外部数据候选与阻断

DRAMP、HAPPENN 和 HemoPI2 可作为后续公开来源候选。不同数据库可能重复收录同一实验或序列，不能仅按数据库名称宣布独立。当前尚未导入任何通过端点、证据、许可及跨来源同源检查的独立外部队列。

当前开发试采样的 417 条序列已经形成单一 40% 连通簇。追加来源不会拆开这个已有连通簇；必须先对隔离定义和研究范围作出有科学依据、前瞻记录的决定，不能自动放宽阈值或删除桥接序列以换取高分。
