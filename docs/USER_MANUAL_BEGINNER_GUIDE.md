## 一、30 秒极速上手（3 步走通第一次预测）

如果你刚刚接触这个平台，不需要看复杂代码，只需按下面 **3 步** 操作：

1. **点击经典药靶对**：在预测页面上方，点击快捷标签按钮 **「达沙替尼 → ABL1」**（系统会自动填入该药物和激酶）。
2. **选择推荐模型**：默认已高亮选中 **「★ 第二代生物世界模型 (Stacking 集成)」**（无需更改）。
3. **点击大蓝按钮**：点击 **「执行单点结合亲和力预测 (Predict)」**。
4. **见证奇迹**：2 秒内，右侧会弹出结果：
   * **预测亲和力 (pKd)**：`6.98` 左右（越大越好）；
   * **解离常数 (Kd)**：`105.4 nM`（越小活性越高）；
   * **3D 物理透视**：告诉你它属于哪种构象模式（Type I 还是 Type II），以及范德华力、静电引力等物理自由能分解！

### 1. 启动命令（在 Windows PowerShell 中）

如果你是从零启动本地服务，在项目根目录运行：


## 三、界面布局与模块全景导览

整个平台界面采用了 **「量子生物高精控制台」** 风格，主要由三大区域构成：

1. **顶部导航栏 (Global Header)**：
   * **运行状态指示灯**：绿色呼吸灯表示后端 7 个预训练模型与 68 药/379 激酶数据库已全部热加载就绪。
   * **功能 Tab 标签**：
     * **`DTI 激酶亲和力`**：核心预测工作台（默认主页）。
     * **`先导改构与进化`**：AI 自动把药物分子进行结构微调升级。
     * **`螺旋轮两亲投影`**：查看多肽分子的 2D/3D 极性物理分布。
     * **`科研报告与导出`**：学术级报告汇总与数据导出。
   * **右上角工具**：
     * **太阳/月亮图标**：一键切换白昼洁净实验室模式 / 深邃夜间暗黑模式。
     * **模型配置**：选配大语言模型（如 Gemini / OpenAI / 本地 Ollama），用于生成更丰富的药化解说文本。
     * **分子库 (购物车)**：暂存你感兴趣的分子，支持一键批量导出 CSV。

## 四、核心功能 1：DTI 激酶结合亲和力预测

这是最常用的功能，用于预测**某个小分子药能不能结合上某个激酶靶点、结合得牢不牢固**。

### 操作步骤：
1. **输入小分子抑制剂 (Small Molecule)**：
   * **下拉框快速选择**：在「预置药物」下拉菜单中挑选 68 种经典药物（如达沙替尼、吉非替尼、伊马替尼、索拉非尼等）。
   * **或者自己填 SMILES**：如果你合成了新分子，清空输入框，把分子的 SMILES 代码粘贴进去。
   * **展开 2D 骨架**：点击右上角「展开 2D 骨架」，可以直接看到分子像 ChemDraw 一样的平面化学结构！
2. **输入激酶受体 (Kinase Target)**：
   * **下拉框挑选靶标**：在「379 种人类激酶」下拉框中挑选（如 ABL1、EGFR、BRAF、KIT、SRC 等）。
   * **或者自己填氨基酸序列**：支持输入自定义突变激酶序列（如含 T315I 突变耐药位点）。
3. **选择预测引擎**：
   * 强烈推荐保留默认的 **「★ 第二代生物世界模型 (Stacking 集成)」**。这是集成了 Uni-Mol 3D 几何特征与 ESM-2 进化生物学全长表征的旗舰模型，在国际金标准 DAVIS 双盲测试中表现最强（CI 一致性指数达 0.865）。
4. **点击执行**：
   * 点击 **「执行单点结合亲和力预测」**，右侧立刻呈现推断结果；
   * 若想了解该药物是否专门针对该激酶、会不会“误伤”其他激酶，点击右下角 **「激酶谱系选择性分析」**，系统将在 14 种代表性激酶上横向排查活性！

## 五、核心功能 2：小白必读——科研输出结果白话速查字典

右侧弹出的各种生化物理指标到底是什么意思？请看下表通俗解读：

| 专业指标名称 | 显示示例 | 通俗大白话解释 | 怎么判断好坏？ |
| :--- | :--- | :--- | :--- |
| **pKd (负对数亲和力)** | `6.977` | 药物与靶点的结合强度对数打分。数值每增加 1，结合力增强 10 倍！ | **数值越大越好**：<br>* `< 6.0`：弱/非特异性结合<br>* `6.0 ~ 7.0`：中等纳摩尔级结合<br>* `7.0 ~ 9.0`：强效靶向药<br>* `> 9.0`：超强皮摩尔级（神仙药） |
| **Kd (解离平衡常数)** | `105.4 nM` | 结合一半靶标所需要的药物分子浓度。单位有 $\mu\text{M}$（微摩尔）、$\text{nM}$（纳摩尔）、$\text{pM}$（皮摩尔）。 | **数值越小越好**（越小代表只需要极微量就能起效，药效极强且副作用小）。 |
| **3D 诱导契合构象** | `Type I (dfg_in)` | 药物插入激酶口袋的物理姿势：<br>* **Type I (DFG-in)**：直接插入活性开门构象；<br>* **Type II (DFG-out)**：强行把天冬氨酸残基拧转开门，插入变构深口袋。 | 属于构象机制定性判断。Type II 通常更具激酶选择性，但要支付空间翻转能垒（`dfg_flip_penalty`）。 |
| **MM-GBSA 自由能 ($\Delta G_{bind}$)** | `-178.67 kcal/mol` | 第一性原理物理结合总能量。严格等于范德华力 + 静电引力 + 溶剂化排阻 - 构象熵罚。 | **负得越多越牢固**（释放能量越多，结合越稳定）。 |
| **$\Delta E_{vdw}$ (范德华引力)** | `-146.7` | 分子间贴合产生的微观色散引力（相当于两个零件表面严丝合缝扣在一起）。 | 负值，绝对值越大贴合越好。 |
| **$\Delta E_{elec}$ (静电偶极)** | `-63.7` | 正负电荷和氢键引起的电学吸引力（相当于磁铁相吸）。 | 负值，提供特异性定位。 |
| **$\Delta G_{solv}$ (溶剂化效应)** | `-37.3` | 分子把周围水分子挤开、形成油性疏水核心的自由能变化。 | 负值有利于疏水结合。 |
| **$-T\Delta S$ (熵罚损失)** | `+5.6` | 自由旋转键被绑住不能随便晃动而付出的自由度惩罚代价。 | 正值惩罚项，越小越好。 |

## 六、核心功能 3：AI 先导物智能改构与分子进化

当一个药物结合力还可以，但你希望**让它结合更紧密、代谢更稳定或规避耐药突变**时，使用该功能。

### 操作步骤：
1. 点击顶部导航栏 **「先导改构与进化 (Lead Optimizer)」**；
2. 选择基础药物（例如选择「达沙替尼」）；
3. 选择核心优化目标（如：`提升亲和力与结合强度`、`引入增溶侧链改善成药性` 等）；
4. 点击 **「开始智能改构与贝叶斯主动学习评估」**；
5. **查看改构分子阶梯榜 (Ladder View)**：
   * 系统会自动生成 4 种化学合法的改构体（如单氟取代、甲基化封闭、生物电子等排体替换）；
   * 列表会按预测结合力从强到弱排好；
   * 如果看到 **$\Delta pKd = +0.645$**，代表亲和力提升了近 4.4 倍！点击「存入分子库」即可收藏。

## 七、核心功能 4：贝叶斯主动学习探索/利用四象限

在药物研发中，合成和测试一个分子非常昂贵。**面对 AI 生成的一堆分子，先做哪一个实验最划算？**

点击「贝叶斯主动学习探索/利用矩阵」标签，系统会用数学获取函数将分子自动划入四个象限：

```
                ▲ 预测亲和力均值 (μ)
                │
   【Q1: 高置信度领头物】 │ 【Q2: 突破假说】
   · 胜券在握，必定有效    │ · 高期望提升 (Top EI)
   · 优先投产验证         │ · 冲刺皮摩尔新药 (高回报)
────────────────┼────────────────► 模型不确定度 (σ)
   【Q4: 确定性无效物】   │ 【Q3: 认知盲区】
   · 极弱且确信无效       │ · 认知盲区，高信息增益
   · 直接舍弃，节省经费   │ · 做了能极大提升 AI 聪明度
                │
```

* 🚀 **Q1 领头物 (Hits)**：推荐指数 ⭐⭐⭐⭐⭐。直接推进生化活性测定。
* 💎 **Q2 突破假说 (Breakthrough)**：推荐指数 ⭐⭐⭐⭐。期望提升（EI）最高，最具爆款潜力。
* 💡 **Q3 认知盲区 (High-Info)**：推荐指数 ⭐⭐⭐。适合学术探索，能帮算法长见识。
* ❌ **Q4 确定性无效 (Inactives)**：推荐指数 0。坚决不要花钱做实验。

## 八、分子暂存库与数据导出

1. **存入分子库**：在任何分子卡片旁点击「存入分子库」，右上角购物车数量会实时增加。
2. **打开分子库**：点击右上角「分子库」按钮，弹出浮窗，可以查阅所有暂存分子的化学式、预测活性与入库时间。
3. **导出 CSV**：点击浮窗右下角「导出为 CSV」，可以一键把数据导出到 Excel 中，直接用于组会汇报或实验记录。
4. **一键复制报告**：在主动学习页面点击「复制学术总结」，可以把带有 Markdown 表格的排版文字直接粘贴到微信、邮件或飞书中。

## 九、常见问题与避坑指南 (FAQ)

### Q1：SMILES 字符串是什么？我该去哪里查？
> **答**：SMILES 是用字母和括号表示小分子二维化学结构的通用代码（例如乙醇是 `CCO`，阿司匹林是 `CC(=O)OC1=CC=CC=C1C(=O)O`）。  
> 查法：在 [PubChem (NCBI)](https://pubchem.ncbi.nlm.nih.gov/) 搜索药名，在页面中的 **Canonical SMILES** 处复制即可。

### Q2：我没有配置大语言模型 (LLM) API Key，能正常使用吗？
> **答**：**完全可以正常使用！**  
> 系统内嵌了强大的药化第一性原理启发式引擎，无需网络与 API Key 即可全自动生成改构体、打分和计算自由能。只有当你希望大模型用中文给你写长篇故事性药理假说时，才需要在「模型配置」里输入 Key。

### Q3：AI 预测的结果可以直接替代实验室真实的细胞实验或临床用药吗？
> **答**：**绝对不行！**  
> 本系统为科研计算与虚拟筛选辅助工具，用于帮助科研人员缩小实验范围、节省试剂成本。所有计算产物必须由化学家进行合成，并通过体外酶活抑制实验（IC50/Kd 测定）及动物安全性毒理评价后方可用于后续研究。

### Q4：预测很慢或者卡住怎么办？
> **答**：
> 1. 单点预测通常在 1 秒内完成；若超过 5 秒，请检查顶部绿色指示灯是否在线。
> 2. 激酶全谱扫描需同时测定 14 种激酶，约耗时 2~3 秒，属正常现象。
> 3. 若前端出现红字提示，点击右上角太阳/月亮图标或刷新页面（`F5`）即可重置。
