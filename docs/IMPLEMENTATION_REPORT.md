# SafeAMP-Dual 本地整改交付记录

日期：2026-09-28。范围：研究数据和实验基础设施、正式推理失效保护、现有工作台的数据契约和科研措辞、论文证据与声明。未执行远程部署、推送或投稿。

## 已落地的软件变更

- public_data.py：原始 DBAASP 记录缓存、版本/抓取信息、来源与文献、实验条件、保守的区间及单位转换；未知和冲突结果保持缺失。
- research_data.py：逐条证据检查、原始文件哈希、DBAASP 标签重新派生校验、显式观察标记、冲突合并、全成员序列一致性及来源隔离门禁。
- experiment_runner.py：七模型、三种子、五折分组接口，训练内预处理，OOF 校准和阈值，完整开发集重训，全部预测及模型产物保存。
- evaluation.py / publication_artifacts.py：从持久化预测生成指标、混淆矩阵、校准信息、三种子均值、簇置信区间和配对比较；失败运行不得导出论文结果。
- inference_runtime.py / research_api.py：检查真实 ESM、权重、代码和特征版本；未配置或不匹配时 HTTP 503，非法输入 HTTP 422，健康状态不再假报。
- React 工作台：统一 API 字段与错误处理，取消虚构论文引用、临床评级和降毒机制断言，固定理化提示取代“梯度归因”；长肽螺旋轮分环显示，避免残基叠盖。
- 文档和旧资产：模拟数据、无证据旧结果及图退出活动结果目录；旧权重明确标为未验证；活动 LaTeX 是不可投稿的协议草稿，声明未核实即留空。

## 实际执行结果

公开数据试采样得到 417 条记录，抗菌标签 253 阳性、138 阴性、26 未知；溶血标签 18 阳性、44 阴性、355 未知。原始数据和标签通过本地完整性与派生检查，不代表原始论文已经完成逐条人工复核。

在已固定的 40% 全成员一致性连通规则下，417 条序列属于一个簇，且没有通过验证的外部来源队列。准备和训练调用均明确阻断。没有产生新的正式分类器、性能表、消融结果或显著性结论。

原文献库 35 项已逐项尝试元数据核验，修订后保留 34 项；一个无法证实的报告条目退出活动库。修订库中 29 项 DOI 的题名、作者和年份元数据一致，5 项无 DOI 记录仍需原始来源核对。所有引用用途仍待作者对照原文核实，不能表述为“全部文献已验证”。审计轨迹见 04_paper/evidence/。

## 验证与边界

- 当前研究单元测试及原有螺旋轮测试：56 项通过；见 output/verification/pytest.xml 和 pytest.txt。
- 26 个活动 Python 文件通过 AST 语法解析。
- 官方 fair-esm 实际加载，生成有限的 320 维池化和 20×320 残基嵌入，校验文件见 output/verification/real_esm_check.json。这不是模型效果验证。
- 前端 TypeScript 检查和生产构建通过；lint 返回成功，有 4 条未使用项/React 开发体验类警告，完整日志见 output/verification/frontend-lint.txt。
- 真实浏览器执行模型不可用提示、非法输入拒绝、突变及报告失效保护、26 残基投影与移动端检查。脚本和截图在 output/playwright/，复核日志在 output/verification/browser.txt。
- 正式出版导出针对失败运行被拒绝，未生成输出目录。
- LaTeX 内置编译器报告环境错误：Unable to find standard directories for platform。源文件已保留并请求打开编辑器；未确认 PDF 编译成功。
- 历史独立演示/远端集成脚本不属于当前 pytest 收集范围，也未对未授权的公网服务运行测试。
