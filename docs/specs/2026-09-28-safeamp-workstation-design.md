## 2. 四大专业科研工作台详细设计

### 2.1 工作台 1：高通量协同筛选台 (Screening Studio)
* **功能目的**：面向湿实验研究人员和计算生物学者，支持单条或成百上千条多肽的并发活性与溶血毒性评估。
* **输入支持**：
  - 纯文本序列框（支持多行天然氨基酸单字母，自动过滤空白与非法字符）；
  - FASTA 格式自动解析（支持 `>header` 提取）；
  - 5 组预置快捷典型案例：🐝 蜂毒素 Melittin（高毒）、🐸 爪蟾肽 Magainin-2（安全）、🧬 人源 LL-37、✨ 优化降毒肽 Melittin-L13R、🧪 短测试肽 ADAD。
* **统计看板与 Pareto 分布图**：
  - **全局指标摘要**：总筛选条数、Tier-1 优质候选数、Tier-3 高毒分子数、平均治疗安全指数 (TSI)；
  - **SVG 双效散点分布图 (Pareto Frontier)**：
    - 横轴：溶血毒性概率 $P_{Hemo}$ (0.0 ~ 1.0)
    - 纵轴：杀菌活性概率 $P_{AMP}$ (0.0 ~ 1.0)
    - 气泡颜色/大小：映射综合安全指数 TSI；
    - 高亮标注黄金候选区（左上角：强杀菌、极低溶血）。
* **分子结果卡片**：
  - 核心数值指标（$P_{AMP}$、$P_{Hemo}$、TSI、评级 Tag）；
  - 4 AA 短肽友好科学提示（说明天然抗菌肽通常为 10~50 残基）；
  - 残基级双向属性彩色热力图（绿色=杀菌结合贡献，红色=溶血插入元凶）；
  - **交互动作**：
    - `[📥 存入候选库]`：加入全局暂存箱；
    - `[⚡ 送入突变降毒]`：一键跳转至工作台 2 并载入该分子；
    - `[🌀 绘制螺旋轮]`：一键跳转至工作台 3 并绘制投影。

---

### 2.2 工作台 2：AI 定向突变实验室 (Directed Evolution Lab)
* **功能目的**：模拟湿实验定向进化（Directed Evolution），针对具有强杀菌能力但伴随严重溶血毒性的母体多肽，精准打掉溶血疏水核心。
* **分子输入**：
  - 可直接从下拉框选择「暂存箱中的候选分子」，或手动粘贴输入序列；
* **进化选择压参数微调 (Evolution Constraints)**：
  - **杀菌保留底线**：$P_{AMP} \ge 0.85$（防止突变后丧失抑菌能力）；
  - **期望溶血降幅**：$\ge 50\%$；
* **演化突变产物展示**：
  - **Top-3 最优单点突变推荐列表**；
  - **前后指标并排对比卡片**：
    - 突变位点与氨基酸更替（如 $L13R$：第 13 位亮氨酸突变为精氨酸）；
    - 突变后序列、TSI 增益（+0.683）、溶血降幅（-97.1%）、保留抗菌概率（99.68%）；
    - 深入药理学机理解释（为什么该突变破坏了插入红细胞膜的疏水簇，同时借助正电荷维持了对细菌负电膜的静电吸附）；
  - **跨模块联动**：
    - `[📥 存为改良分子]`：存入全局暂存箱以便后续生成论文报告；
    - `[🌀 对比螺旋轮构象]`：一键送入工作台 3 查看突变前后螺旋面的变化。

---

### 2.3 工作台 3：$\alpha$-螺旋轮与构象投影室 (Helical Wheel Studio)
* **功能目的**：展现多肽在膜结合状态下的空间两亲性（Amphipathicity），是抗菌肽 SCI 论文中最核心的机理图。
* **算法实现**：
  - 遵循经典 Schiffer-Edmundson 投影模型，每个残基沿圆周旋转 $100^\circ$；
  - **残基物化属性配色标度**：
    - 疏水非极性（L, I, V, F, W, M, A）：橙黄色/深红色；
    - 碱性阳离子（K, R, H）：天蓝色（杀菌膜锚定）；
    - 酸性阴离子（D, E）：洋红紫色；
    - 极性不带电（S, T, N, Q, G, P, C, Y）：青绿色；
* **物理化学参数计算与渲染**：
  - **Eisenberg 两亲疏水力矩 ($\vec{\mu_H}$)**：计算并在轮心绘制矢量指针箭头，直观表达多肽的两亲极性强度；
  - **疏水面跨度角度 ($\theta_{hydro}$)**：统计连续疏水残基圆周弧度；
* **论文配图导出**：
  - 提供 `[📥 导出高清 SVG / PNG]` 按钮，纯矢量超清导出，可直接嵌入学术论文。

---

### 2.4 工作台 4：科研报告与导出工坊 (Report & Export Studio)
* **功能目的**：一键汇总结算成果，产出可直接用于论文正文、补充材料（Supplementary Materials）或基金申报书的成套资产。
* **核心内容模块**：
  - **多肽成药性评级**（Tier-1 理想候选、Tier-2 中等潜力、Tier-3 高效但剧毒）；
  - **膜结合与穿孔机理推导**（Toroidal Pore / Barrel-Stave / Carpet 模型）；
  - **理化多维参数清单**（全长、分子量、净电荷、疏水性、Boman 指数、高危残基数）；
  - **湿实验验证指南**（微量肉汤稀释法测定 MIC、家兔红细胞溶血度 HC50、MTT 细胞毒性方案）；
* **双引擎驱动模式**：
  - **引擎 A（默认）**：内置生物医学确定性规则推理引擎（开箱即用，零延迟）；
  - **引擎 B（扩展）**：接入用户自定义大模型（DeepSeek / Gemini / OpenAI），流式生成包含最新文献观点的 500+ 字深度分析长文；
* **学术资产一键导出**：
  - `[📥 导出完整筛选 CSV]`
  - `[📄 导出专业 Markdown 科研报告]`
  - `[📖 复制标准 BibTeX 论文引用]`

## 3. 全局数据流与接口规范 (Data Flow & APIs)

### 3.1 前端状态管理 (Shared State)
* `peptideCart`: 存储用户收藏的候选分子列表 `[{id, name, sequence, amp_prob, hemo_prob, tsi, source}]`；
* `currentSelectedSequence`: 当前选中的活跃多肽序列；
* `llmConfig`: 存储于浏览器 `localStorage` 中的大模型配置（API Key, Base URL, Model Name）。

### 3.2 后端 API 规范 (FastAPI)
1. `GET /api/system_status`：返回 ESM-2、SafeAMP-Dual Net、优化引擎的模型状态与参数量；
2. `POST /api/predict_batch`：批量接收序列列表，返回预测概率、TSI、残基级热力图与短肽提示；
3. `POST /api/ai_optimize`：接收单条序列与选择压约束，返回 Top-3 定向突变改良方案；
4. `POST /api/helical_wheel`：接收单条序列，返回圆周残基坐标、两亲力矩 $\mu_H$、疏水面弧度与残基色彩分类；
5. `POST /api/ai_report`：接收序列与大模型配置，输出成药性报告与长文推导。
