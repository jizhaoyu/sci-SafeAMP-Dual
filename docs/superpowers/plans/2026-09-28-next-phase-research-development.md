## 一、研究目标、当前基线与工作边界

### 1.1 最终研究目标

围绕以下问题开展可复现的计算研究：

> 在真实实验标签、缺失标签掩码和严格序列隔离条件下，联合学习能否改善抗菌活性与溶血预测的性能权衡及概率校准？

现阶段不预设以下结论：

- 双任务模型一定优于单任务模型。
- ESM 特征一定优于传统理化特征。
- 实验一定出现统计显著性。
- 预测分数可以代表临床安全性、杀菌率、治疗窗口或实测降毒效果。
- 当前架构本身足以构成论文创新。
- 完成开发后一定能够被某个分区或某本期刊录用。

**研究结果允许为阴性、混合结果或条件性结果。执行目标是形成可靠证据，而不是获得预定的高分。**

### 2.1 数据源优先级

#### A. DBAASP：主要开发数据来源

入口：

```text
https://dbaasp.org/
https://dbaasp.org/api?page=rest
https://dbaasp.org/terms-and-conditions
```

DBAASP 提供肽结构、修饰、抗菌及溶血／细胞毒性活性与实验条件，适合作为当前项目的主要记录来源。应优先使用官网文档所指向的接口，不根据旧博客猜测 API。([dbaasp.org](https://dbaasp.org/))

截至本次核查，其官网政策允许访问、下载、使用、改编与再分发数据库数据，同时要求标明 DBAASP 来源。执行时应保存当时的政策版本；数据库政策不自动替代其所引用文章、图片或补充材料的使用条件。([dbaasp.org](https://dbaasp.org/terms-and-conditions))

**本轮指定用途：开发候选数据。**

#### B. DRAMP：外部验证候选的首选入口

入口：

```text
https://dramp.cpu-bioinfor.com/
```

DRAMP 的数据库论文介绍了实验活性、溶血／细胞毒性注释和下载资源，并报告采用 CC BY 4.0。实际执行应记录下载文件标明的版本、许可和时间，不把此前对话提及的版本号当作已核实事实。([pmc.ncbi.nlm.nih.gov](https://pmc.ncbi.nlm.nih.gov/articles/PMC11701585/?utm_source=openai))

**本次直接访问官网出现超时，因此下载地址和可用格式必须在执行时重新核对。**

**本轮指定用途：外部验证候选。不得先混入开发集，之后再从同一批数据中挑选“外部测试”。**

外部候选不等于合格外部队列。还必须检查：

- 是否与 DBAASP 收录了同一篇原始论文。
- 是否包含相同分子或相似序列。
- 实验端点、单位、实验对象是否兼容。
- 是否具有可以定位的原始实验依据。
- 是否存在选择性收录造成的明显偏差。

#### C. PubMed、PMC 与论文补充材料：证据核查及外部来源补充

入口：

```text
https://pubmed.ncbi.nlm.nih.gov/
https://pmc.ncbi.nlm.nih.gov/
```

PubMed 主要用于文献检索和元数据定位，不应被当成全文数据库；PMC 提供部分全文资源。([pubmed.ncbi.nlm.nih.gov](https://pubmed.ncbi.nlm.nih.gov/about/))

自动获取 PMC 内容应使用其允许的官方服务，并逐篇检查许可。不能因为文章能在浏览器打开，就推断允许任意批量抓取和再分发。([ncbi.nlm.nih.gov](https://www.ncbi.nlm.nih.gov/pmc/tools/openftlist/))

建议初始检索式：

```text
("antimicrobial peptide" OR "antimicrobial peptides")
AND (hemolysis OR haemolysis OR hemolytic OR haemolytic)
AND (HC50 OR "human erythrocytes" OR "human red blood cells")
```

抗菌端点补充检索：

```text
("antimicrobial peptide" OR "antimicrobial peptides")
AND "Escherichia coli"
AND ("minimum inhibitory concentration" OR MIC)
```

保存检索式、日期、数据库、结果编号与纳入／排除原因。文献不足时可以扩展检索词，但必须记录变更。

### 2.3 冻结现有研究端点

未获得明确的研究方案修订确认之前，继续采用：

| 内容 | 当前规则 |
|---|---|
| 分子范围 | 10–50 个残基、标准氨基酸、线性、未修饰单体肽 |
| 抗菌阳性 | 大肠杆菌 MIC ≤32 μg/mL |
| 抗菌阴性 | 大肠杆菌 MIC ≥128 μg/mL |
| 溶血阳性 | 人红细胞 HC50 ≤100 μg/mL |
| 溶血阴性 | 人红细胞 HC50 ≥250 μg/mL |
| 中间区间 | 标签未知，不强行二分类 |
| 未测定或证据不清 | 标签未知 |
| 不同实验结果冲突 | 保留原始测量，分类标签按既定冲突规则处理 |

这些是项目的操作性研究定义，不是临床阈值。

特别要求：

1. **化学合成但经过实际实验测定的肽，可以属于真实实验数据。**
2. **计算生成或模型猜测的标签，不得进入正式结果。**
3. 不得把数据库中“未收录活性”解释为阴性。
4. 不得用普通蛋白片段、随机序列或模型低分样本补造实测阴性。
5. 不得将其他动物红细胞的结果自动等同于人红细胞。
6. 不得将“某浓度下溶血百分比”直接改写成 HC50。
7. 不得把“低溶血”“安全”等文字描述直接转换成数值标签。
8. 不得删除修饰信息后把修饰肽当成未修饰肽。

### 2.4 数据组织：保留测量层，派生标签层

建议在现有格式之外，增加一个**实验测量层**，再由统一规则生成现有训练输入。

```text
原始来源文件
    ↓
标准化实验测量记录
    ↓
端点兼容性与单位判断
    ↓
样本级标签、缺失原因及证据关联
    ↓
序列去重、隔离诊断、固定划分
    ↓
正式训练输入
```

不得只保存最终的序列和 0／1 标签。

测量层最少包含以下字段组：

| 字段组 | 应记录的内容 |
|---|---|
| 来源 | 数据库、来源编号、版本、原始 URL、获取时间 |
| 原始文件 | 路径、SHA256、原始文件内部定位 |
| 分子 | 原始序列、规范化序列、修饰、结构类别 |
| 实验对象 | 菌种／菌株或红细胞来源 |
| 指标 | MIC、HC50 或其他原始指标名称 |
| 测量 | 原始字符串、数值或上下界、边界是否包含、原单位 |
| 条件 | 培养基、时间、温度等来源中实际提供的信息 |
| 文献 | DOI／PMID／其他可核对编号及原文位置 |
| 标签派生 | 规则版本、结果、证据引用、未知原因 |
| 复核 | 机器检查状态、人工复核状态、复核依据 |

必须区分三个不同状态：

```text
measurement_present：是否存在测量记录
endpoint_eligible：是否能用于当前研究端点
label_observed：是否最终形成可训练的分类标签
```

例如，一条记录可能有真实 MIC，但属于其他菌种；也可能有人红细胞 HC50，但落在中间区间。两种情况都不能简单记成“没有实验”，也不能当作阴性。

### 2.5 缺失、单位与冲突规则

建议固定以下未知原因枚举，允许一条记录具有多个原因：

```text
not_measured
incompatible_target
incompatible_endpoint
unsupported_unit
ambiguous_censoring
intermediate_range
conflicting_measurements
unsupported_modification
unresolved_evidence
```

实现必须覆盖：

- `<`、`≤`、`>`、`≥`。
- 数值区间与开闭边界。
- 单位大小写、Unicode 符号和明确的单位别名。
- 无法可靠换算的测量。
- 同一分子在不同实验条件下的冲突结果。

单位转换必须有可审计公式及分子量依据。继续限制为当前协议允许的未修饰分子，不因缺少修饰信息而猜测分子量。

同一测量被多个数据库重复收录时，保留多个来源链接，但不得把它当成多次独立实验。身份不能确定时标记待核查，不通过模糊匹配强行合并。

### 2.7 序列隔离规则与允许的诊断

当前正式定义保持：

```text
global Needleman–Wunsch
match = +2
mismatch = -1
gap = -2
输入按既定字典序规范方向
回溯同分时优先对角线
identity = matches / min(sequence_lengths)
identity ≥ 0.40 的序列对建立连接
连通分量不能跨集合
```

需要区分：

- 一个簇中所有序列两两相似。
- 序列通过中间成员连接到同一个连通分量。

本项目使用后者。增加新记录可能增加新簇，也可能连接原有簇，但不会自动拆开现有连通分量。

允许开展以下诊断：

- 当前规则的完整复算与实现核查。
- 不同长度组合、组成特征与连接度的描述。
- 同一序列对在不同一致性分母下的差异。
- 预先固定的 0.30、0.40、0.50、0.60 阈值下，**仅数据结构层面**的可行性报告。
- GraphPart 的诊断性保留率和隔离结果。

这些诊断不得用于选择“模型分数最高”的隔离方法。

GraphPart 可能通过重新分配或移除序列实现隔离，也可能在高冗余数据上无法找到可行方案。所有删除记录和分布变化必须保留，不能只报告最终通过的部分。([pmc.ncbi.nlm.nih.gov](https://pmc.ncbi.nlm.nih.gov/articles/PMC10578201/?utm_source=openai))

**本轮默认不自动采纳新的阈值、分母或删样本策略。**如果当前规则仍不可行，应输出一份方案修订建议，等待负责人明确决定，同时继续完成不依赖该决定的软件和证据整理。

### 阶段 3：证据抽查与数据覆盖度报告

**目标：确定数据是否足以支持研究问题。**

报告至少包含：

- 来源和原始论文的数量及贡献比例。

- 各来源和实验条件下的标签分布。
- 原始论文高度集中的情况。
- 数据收集方式可能造成的偏差。

**人工复核安排：**

- 优先复核拟进入正式数据的全部可用溶血标签。
- 优先复核全部外部评估候选的标签证据。
- 抗菌开发记录至少抽查 50 条；不足 50 条时全部检查。

- 单独列出修饰、区间、单位转换和冲突处理案例。

上述抽查数量是本轮工作量安排，不是统计充分性的证明。

Gemini 可以准备对照材料、定位证据并记录机器检查结果，**不能自行把检查结果写成已经完成“人工复核”**。未完成的人工工作保持待确认状态。

**验收：**

- 明确回答数据主要缺在何处。
- 不以“记录总量达到某个数字”代替独立样本量和标签覆盖度分析。
- 不通过补造阴性或优先选取容易预测的记录提高数量。
- 不宣称数据库注释已经等同于原始论文人工复核。

### 阶段 7：统计评估与正式研究产物

主指标沿用：

```text
溶血任务 Average Precision
论文中可标为 AUPRC，但必须说明采用 Average Precision 定义
```

同时报告：

- 两个任务的 AUROC。
- MCC。
- 混淆计数。
- 敏感度与特异度。
- Brier score。
- 校准分箱信息。
- 每个指标的实际观测样本数、阳性数、阴性数。
- 独立序列簇数量。
- 三个种子的结果及指定集成结果。

继续遵守：

- 阈值只由开发数据确定。
- 当前 OOF 预测参与校准和阈值选择，因此对应结果属于选择用途，不是无偏的最终性能估计。
- 目标特异度不等于测试集实际特异度。
- 置信区间及比较按既定独立簇单位计算。
- 不把五折或三个种子当作独立受试对象。
- 单类别重采样不能伪造 AUROC 或显著性结果。
- 保留无效重采样数量和有效比例。
- 比较对象及多重检验规则预先确定。
- 原始分数和校准分数的结果按现有方案保存。
- 区间若不包含训练数据变化带来的不确定性，应在方法中说明。

数据中阳性率、抽样方式不同的队列，应报告其差异，不能仅用不同队列的 AUPRC 大小推断哪个模型更优。

**验收：**

- 删除生成的汇总产物后，可以从保存的预测重新生成相同结果。
- 任一论文数值能追溯到运行、样本、标签、概率和计算方法。
- 失败或不完整运行无法导出看似正式的研究结果。
- 无显著提升时如实报告。
- 不根据有利结果临时增删比较对象。

- 上一次失败原因是否仍成立。

不能只凭“文件存在”就跳过验证。

输入、端点定义或关键代码变化后，创建新运行版本。禁止混用新旧实验单元拼成同一完成运行。

### 4.5 必须实现或补齐的测试

| 类别 | 具体场景 | 预期结果 |
|---|---|---|
| 标签缺失 | 没有溶血实验 | 保持未知，掩码关闭 |
| 中间区间 | MIC 位于 32 与 128 之间 | 不产生二分类标签 |
| 截断测量 | HC50 `>100` | 不能直接判为 ≥250 |
| 明确阴性 | HC50 `≥250` 且其他条件兼容 | 可派生当前端点阴性 |
| 目标不兼容 | 兔红细胞测量 | 不作为人红细胞 HC50 标签 |
| 指标不兼容 | 固定浓度下的溶血百分比 | 不直接转成 HC50 |
| 单位 | 支持单位的明确等价输入 | 派生结果一致 |
| 单位 | 不支持或缺少单位 | 未知并记录原因 |
| 修饰 | 修饰信息存在或含糊 | 按规则排除或待核查 |
| 合成类型 | 化学合成后实测 | 不因“synthetic”字样误判成虚构标签 |
| 重复测量 | 两数据库复制同一实验 | 不计成独立实验 |
| 冲突 | 同分子出现矛盾测量 | 保留冲突证据，不多数投票 |
| 原始证据 | 文件缺失或哈希变化 | 验证失败 |
| 新来源 | 非 DBAASP 标签与原始测量不符 | 验证失败 |
| 比对 | 输入顺序交换 | 一致性满足规定的对称性 |
| 比对 | 阈值恰为 0.40 | 按当前 `≥` 规则建立连接 |
| 比对 | 长短不同、回溯同分 | 与冻结定义一致 |
| 分组 | A 连 B、B 连 C、A 不连 C | 正确形成同一连通分量 |
| 跨集合 | 非代表成员违反阈值 | 能检出并阻断 |
| 来源隔离 | 同一原始论文跨开发／外部候选 | 外部候选不通过 |
| 类别覆盖 | 某任务评估部分只有一类 | 正式流程阻断 |
| 预处理 | 测试记录改变 | 训练拟合参数不随之改变 |
| 特征 | 真实模型加载失败 | 不使用伪嵌入 |
| 运行恢复 | 中断后参数变化 | 拒绝混用旧运行 |
| 预测 | 样本、模型或种子缺失 | 完整性验证失败 |
| 导出 | 未完成训练尝试生成论文结果 | 明确拒绝 |
| 服务 | 未配置正式模型 | 503，健康信息准确 |
| 输入 | 非法序列 | 422 或既有明确验证错误 |

测试数据可以是人工构造的软件夹具，但必须留在测试范围内，不能流入正式来源目录或论文统计。
