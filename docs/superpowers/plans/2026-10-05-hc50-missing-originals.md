# 缺失原文候选跟进实施计划

> **For agentic workers:** 使用现有工具与仓库约定按顺序执行，复选框记录真实验收。

**Goal:** 对当前44条缺原文候选的28个研究来源再次查找公开原文，保存可核查的端点决定和访问缺口。

**Architecture:** 冻结累计78条清单 → 按原测量论文归并 → 公开原文获取 → 逐记录复核 → 来源/覆盖/摘要验收。所有生成产物使用新目录。

**Tech Stack:** 当前Python、标准库、BeautifulSoup、PyMuPDF；不安装依赖。

## 全局约束

`protocol-amd-02`、>=0.40全员同源门禁、分子形式与标签规则保持原样。不得将预测、摘要、动物红细胞、单点溶血或MBC转换为正式标签；来源未取得不等于测定不存在。新训练、协议修订、消息发送与远程推送均不在本批范围。
