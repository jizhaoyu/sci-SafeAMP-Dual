## 1. 核心结论与最终出口裁决 (Final Exit Determination)

> [!IMPORTANT]
> **终审裁决：正式达成 EXIT B（突破性达成候选靶点筛选模型）**
> * **科学突破**：引入 **ESM-2 (480维) + 双线性潜变量特征交叉网络 (`BilinearInteractionDTI`)** 后，在严格 4 折实体隔离测试中，双冷 Top-10 命中率（Dual-Cold P@10）由加性线性 Tobit 的 `0.0417` 跃升至 **`0.1615 ± 0.0243`**，跨越事先预先登记的突破门禁（$P@10 \ge 0.1500$）。
> * **机制证伪与突破**：跨药物 Spearman 排序相关性由加性模型的 `1.0000`（完全退化、所有药物给出相同靶点排序）骤降至 **`0.1003`**，成功证明了药物特异性候选排序分布的成立。
> * **交付建议**：确立双线性交互网络为主要交付候选模型，归档 Phase 3 全流程审计，推进成果沉淀与 Web 预测端服务更新。

## 3. 逐测定数据血缘解耦审计 (Assay Lineage Audit)

- **野生型激酶靶点（Closed Wild-Type）**：
  - 共包含 **355 个野生型靶点**，对应 **14,664 条配对记录**（占比 **93.38%**）；
  - 均具备完全闭合的 UniProt 官方参考 Accession 编号及标准化规范序列。
- **突变体/变体靶点（Closed Mutant Constructs）**：
  - 共包含 **23 个明确突变体靶点**（如 `BRAF(V600E)`、`EGFR(T790M)`、`FLT3(R834Q)` 等），对应 **988 条配对记录**（占比 **6.29%**）；
  - 状态标记为 `CLOSED_MUTANT`，保留生物学真实突变状态，不在训练中强制抹除突变位点。
- **受限工作别名（Restricted Alias）**：
  - 共包含 **1 个靶点**（`ABL1p` 磷酸化变体 working alias），对应 **52 条配对记录**（占比 **0.33%**）；
  - 标记为 `RESTRICTED_ALIAS`，受限参与主干特征训练。

全量 15,704 条记录均具备确定性血缘溯源与状态标签，达成 100% 审计闭环。
